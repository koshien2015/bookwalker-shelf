# bookwalker-shelf

BOOK☆WALKER の購入済み書籍一覧（`https://bookwalker.jp/holdBooks/`）を、シリーズごとのカード表示に切り替える Chrome 拡張。

- シリーズ単位のカード（表紙・所持冊数・未読/読みかけの件数・未購入の既刊あり）
- カードを開くと巻を既刊順に並べ、未読・読みかけ（進捗 %）・既読を表示
- シリーズ名・書名での絞り込み、「未読・読みかけのあるシリーズのみ」
- 「元の表示に戻す」で本来の一覧に切り替え（既読の変更などは元の表示で行う）

## 仕組み

本棚ページ自身が使っている `/prx/holdBooks-api/hold-book-list/` から一覧を取得する。

- 初回と「全件取り直す」: 配信日順で全ページ（50 件/ページ）とシリーズ情報を 1 秒間隔で取得し、`chrome.storage.local` に保存
- ページを開いたとき（前回から 5 分以上経過時）と「最新に更新」: 読んだ順・購入日順の書籍と、購入日順のシリーズの 1 ページ目だけを取り直して反映（3 リクエスト）
- 巻の並び: 全巻のタイトルから重複なく巻数が取れれば巻数順、取れなければ配信日順

## 使い方

```sh
pnpm install
pnpm build
```

1. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選ぶ
3. 本棚ページを開き、「本棚を取得する」を押す

コードを変更したら `pnpm build` し、拡張機能ページで再読み込みする。

## 開発
